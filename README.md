# School Management System 🏫

A Flask-based web application designed to streamline school administration, featuring student management, teacher management, attendance tracking, and fee management.

## Features 🚀
* **Student Management:** Add, update, and view student profiles.
* **Teacher Management:** Manage faculty details and assignments.
* **Attendance Tracking:** Keep records of student and teacher attendance.
* **Fee Management:** Monitor and track fee payments.

## Tech Stack 💻
* **Backend:** Python, Flask
* **Database:** SQLite / SQLAlchemy
* **Frontend:** HTML, CSS, JavaScript
